# Deep Game

built with HTML, CSS, and JavaScript.

## Overview

The player controls a diver descending into the ocean, collecting valuable items while managing oxygen and avoiding underwater obstacles. Each dive is focused on reaching greater depths, collecting resources, and improving the next run.

## Highlights

- Canvas-based 2D gameplay with real-time movement and collision detection
- Progressive underwater environments that become darker with depth
- Multiple obstacles and collectible objects with different behaviors
- Oxygen and health management during each dive
- Gold collection and persistent progression
- Upgrade system for health and oxygen capacity
- Bottle-based story progression
- Boosters that change the conditions of a dive
- Results, best-depth tracking, and progression systems
- Touch and mouse controls
- Custom UI, animations, particles, effects, and sound design

## Design

A significant part of the project focuses on the visual experience. The interface, underwater environment, characters, obstacles, animations, HUD, menus, and feedback effects were designed and implemented specifically for the game rather than relying on external game frameworks.

The goal was to create a simple gameplay loop that feels responsive and visually polished while keeping the game lightweight and playable directly in the browser.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas
- basic Web Audio API

## Gameplay

Dive deeper, collect resources, manage your oxygen, avoid obstacles, and use your earnings to improve future dives. Each run contributes to your overall progression and encourages you to push your depth record further.
